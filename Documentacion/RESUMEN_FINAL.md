## 🛠️ LENGUAJES Y TECNOLOGÍAS UTILIZADAS

### **FRONTEND** (Lo que ves)
```javascript
// LENGUAJES BASE
HTML5           → Estructura web semántica
CSS3            → Estilos y diseño responsivo
JavaScript ES6+ → Lógica interactiva del cliente

// FRAMEWORK PRINCIPAL
Vue 3           → Framework progresivo para UI reactiva
                → Composition API (moderno)
                
// HERRAMIENTAS COMPLEMENTARIAS
Vue Router 4    → Enrutamiento SPA
Pinia           → Gestión de estado
Bootstrap 5     → Framework CSS para diseño
Axios           → Cliente HTTP para API
Leaflet.js      → Mapas interactivos
Nominatim API   → Reverse geocoding

// BUILD TOOL
Vite            → Bundler rápido (desarrollo y producción)
```

### **BACKEND** (Lógica servidor)
```javascript
// LENGUAJE
JavaScript      → Código ejecutado en servidor (Node.js)

// FRAMEWORK WEB
Express.js 5.x  → Framework minimalista para API REST

// ACCESO A DATOS
MySQL2          → Driver para comunicación con MySQL

// SEGURIDAD & AUTENTICACIÓN
jsonwebtoken    → Autenticación mediante JWT
Bcrypt          → Hash seguro de passwords

// MIDDLEWARES & UTILITARIOS
Multer          → Subida de archivos (imágenes)
CORS            → Control de acceso cross-origin
cookie-parser   → Parsing de cookies
dotenv          → Variables de entorno

// DESARROLLO
Nodemon         → Auto-reload during development
```

### **DATABASE** (Persistencia datos)
```sql
MySQL 8.0.x     → Base datos relacional
                → ACID compliance garantizado
                → Foreign keys para integridad
                → Índices para optimización
```

### **INFRAESTRUCTURA & DEPLOYMENT**
```yaml
Docker          → Containerización de servicios
Docker Compose  → Orquestación multi-container
Nginx           → Reverse proxy (desarrollo)
Traefik         → Advanced routing (producción)
```

## ✨ PUNTOS CLAVE PARA MEMORIZAR

### Qué es TerretaShop
Marketplace B2C que conecta **productores locales** con **consumidores cercanos** mediante búsqueda por geolocalización. Sin intermediarios, sin logística, solo conexión directa.

### Stack Tecnológico
- **Frontend**: Vue 3 (JavaScript framework) + Bootstrap (estilos) + Leaflet (mapas)
- **Backend**: Node.js/Express (API REST) + MySQL (base datos)
- **DevOps**: Docker + Nginx

### Números que impresionan
- **15+ endpoints** API funcionales
- **6+ vistas** completamente operativas
- **7 tablas** de base datos relacionales
- **7 documentos** técnicos exhaustivos
- **MVP completado** listo para demostración

### Viabilidad
- Costos bajos (€50-100/mes)
- Modelo de negocio sostenible (Freemium + Publicidad)
- Mercado real (tendencia +35% compras locales)
- Impacto social (reducción desperdicio, economía local)
